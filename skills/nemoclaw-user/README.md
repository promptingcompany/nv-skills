# NemoClaw User

User-facing NemoClaw guidance for installing, configuring, operating, securing,
monitoring, and troubleshooting NemoClaw sandboxes.

This package consolidates the `nemoclaw-user-*` skill prompts into one top-level
skill at `skills/nemoclaw-user/`. The canonical agent entrypoint is
[`SKILL.md`](SKILL.md), and the bundled source prompts are indexed in
[`skills.md`](skills.md).

## Contents

- `SKILL.md` - top-level agent-facing routing prompt
- `skills.md` - index of bundled NemoClaw user skill prompts
- `metadata.json` - package version, organization, and abstract
- `INSTALL.md` - installation notes for common agent runtimes
- `references/` - copied `nemoclaw-user-*` prompts and their supporting files

## Source

The bundled references are copied from the NemoClaw user skills mirrored under
`skills/NemoClaw/nemoclaw-user-*`.
